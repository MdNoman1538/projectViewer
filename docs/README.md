# Documentation

| Path | Holds | Updated |
|---|---|---|
| [project-status.md](project-status.md) | What exists now vs the roadmap; known issues; measurements | End of each phase, and when something significant changes |
| [roadmap.md](roadmap.md) | Phases, goals, performance principles | When a phase is re-scoped or done |
| [decisions/](decisions/) | Architecture Decision Records (ADRs): context, options, decision, consequences | For every significant or hard-to-reverse decision |
| [devlog/](devlog/) | One entry per session: what we did, what surprised us, why we decided things | Every session |

Conventions:
- ADRs are numbered `NNNN-title.md` and never rewritten once accepted; a new ADR supersedes an old one.
- Devlog files are named `YYYY-MM-DD-topic.md` and record reasoning and dead ends.
- Numbers come from measurements that were actually run, with the method stated.
